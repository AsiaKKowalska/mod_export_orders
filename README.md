# Mod Export Orders

Moduł PrestaShopa 1.7.8.10 do eksportu zamówień do pliku CSV z możliwością filtrowania po statusach i produktach.

## Funkcje

- ✅ Filtrowanie zamówień po statusach
- ✅ Filtrowanie zamówień po produktach
- ✅ Export do CSV z danymi: imię, nazwisko, numer zamówienia, telefon, data, kwota
- ✅ Interfejs administracyjny w PrestaShopie
- ✅ Obsługa kodowania UTF-8

## Wymagania

- PrestaShop 1.7.8.10
- PHP 7.4+

## Instalacja

1. Pobierz moduł
2. Umieść w folderze `modules/mod_export_orders`
3. W panelu administracyjnym PrestaShopa: Moduły → Menedżer modułów
4. Wyszukaj "Export Orders" i zainstaluj

## Użytkowanie

1. Przejdź do Zamówienia → Export Orders
2. Wybierz status zamówienia (opcjonalnie)
3. Wybierz produkt (opcjonalnie)
4. Kliknij "Pobierz CSV"
